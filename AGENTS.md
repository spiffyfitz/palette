
# Palette — Codex Instructions

## Git and Version Control

- NEVER create Git commits automatically.
- NEVER push changes to any remote repository.
- NEVER create, delete, or switch Git branches without explicit permission.
- NEVER run destructive Git commands such as git reset --hard, git clean, or git restore.
- You may use read-only Git commands such as git status, git diff, and git log.
- Leave all code modifications uncommitted in the working tree.
- The user is solely responsible for deciding when to commit changes.
- Do not include Git commits as part of milestones or task completion.
- At the end of each task, summarize the changed files and tests performed, but do not commit.
