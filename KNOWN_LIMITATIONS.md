# Known limitations

- This is a runnable foundation with core Paint editing, Phase 3 file workflows and the first Phase 4 blend/coverage/mask and Phase 5 processing slices, not complete Paint/Photoshop equivalence. Disabled controls identify unfinished functionality.
- `.paint` support is experimental and limited to the verified direct 8-bit RGBA unci/iovl graph, whole-item Deflate/zlib or packed raw pixels. The supplied two-layer specimen and generated files round-trip locally. The user confirms generated output opens and looks correct in Microsoft Paint. Independent layer editing there and saving back have not been reported/tested; no broader variant compatibility is asserted. General HEIF/HEIC, nested derived sources, tiled/other bit depths, unsupported essential properties and unknown metadata preservation remain unsupported. See docs/PAINT_RESEARCH.md.
- Only Windows in this environment has been built and launched. The CI matrix is configured, not evidence of successful macOS/Linux runs. Windows 10 is not tested here.
- The UI has been compared with the screenshots and supplied Paint video but is not pixel-identical. Native title bars vary by OS. Palette retains 100% default zoom, its added tab strip and third slider. Menu fade/hover/press and layer-tray transitions approximate the reference; exact WinUI reveal/easing and persistent shape-object controls remain pending. Selected raster content now has live resize/rotation handles. See docs/UI_BEHAVIOR_REFERENCE.md.
- Persistent vector shape objects, additional brush variants, polygon selection, complete mask painting/view/apply/link workflows, layer merging, additional filters and remaining layer styles remain pending. The 137 implemented filters and six effects have functional parameter toolbars with live on-canvas preview; see docs/GALLERY_VIDEO_RENDER_VALIDATION.md. The blend catalog, Wand and basic mask-property UI are functional; that does not establish full Phase 4/5 completion.
- Text is inline during placement and becomes a raster layer on commitment; character/font data is not retained afterward. Only Ubuntu Light and Hack are available. Bold/italic/underline/strike controls are disabled; system fonts, complex shaping and bidirectional layout remain pending. Missing glyphs use a replacement glyph. Limits are 4096 characters, 6-256 px size and a 2048 x 2048 box. egui draws interactive text while Fontdue draws the committed raster; glyph metrics, selection clipping and line spacing can differ. File/tab shortcuts while the text field has focus need further routing work; menu actions finish the draft. Cancel/Escape leaves pixels unchanged.
- One hundred twenty-one filters and six layer styles are live and removable; exact catalog and parameter ranges are in docs/EDITABLE_FILTERS_VALIDATION.md. Registry-driven Apply/Cancel canvas previews use a composite up to 2048 px and can differ from full-resolution output. Gaussian sigma >= 2 uses a three-box approximation, spread uses square max-dilation and most processing works in encoded sRGB. Exposure explicitly decodes/encodes sRGB around a linear-light gain. Filter Gallery, other filters/styles, effect masks and per-effect blending modes remain pending; no Photoshop-identical rendering is claimed. Blur clamps to the original source bounds; styles have separate transparent padding.
- Rulers, nonpixel image-property units and unfinished brush/shape styles are disabled. Custom color slots persist only for the current app session. Image Properties changes canvas bounds; it does not resample pixels or infer missing DPI/metadata.
- Strokes and outlined shapes use maximum coverage against pre-stroke pixels, avoiding opacity buildup at joins. No pressure, spacing, tablet-specific input or brush variants yet. Pencil is a one-pixel hard footprint, not a dedicated integer-line rasterizer. Shape fills use four vertical coverage samples and analytic horizontal spans; curved contours use bounded polygon approximations. Shape previews share geometry and colors with final pixels but do not preview selection coverage, layer masks/blending or live filters. Preview outlines use bounded bevel joins, while CPU strokes use round footprints, so their edge/opacity appearance is not exact parity. Shapes commit as raster pixels on release; post-draw shape-object editing remains pending.
- `.palette` writes v6 binary zlib assets with canvas backing color and original feather contours and reads v1/v2/v3/v4/v5 without overwriting them during migration. The binary format caps manifest size at 4 MiB, unique decoded assets at 512 MiB and file size at 1 GiB. Limits cover stored assets, not total process memory. Older Palette builds reject v6 so custom origins cannot be silently lost; v5 already protected rounded strokes. Version 4 already protected retained original contours. Native versions 1/2 default canvas backing to transparent, preserving their original appearance.
- Images are limited to 64 megapixels; raster imports also limit each dimension to 16384. Images exceeding the GPU texture dimension use a reduced display texture while retaining full source/composite data; high-zoom detail on those images needs tiled display textures. This is not a production-scale 8K editor yet.
- History is capped at 256 commands and 128 MiB of uniquely retained backing buffers beyond the current document. Large destructive operations can exceed that budget and lose their undo entry; render textures, live documents, gesture coverage and structural metadata are outside that budget; retained opaque ICC/Exif buffers are counted. Memory/runtime behavior for fully painted 4K/8K multi-document workloads still needs benchmarking.
- General edits still trigger full background composition. Brush/pencil/eraser samples recompose only changed bounds and upload GPU subimages when a compatible full-resolution display cache exists; reduced display textures and documents containing spatial filters/styles use progressive full background snapshots. Spatial filter painting is live but can lag; it does not run full filters on the UI thread. One full render can be queued; obsolete general-edit epochs cannot overwrite newer state, but running jobs are not cancelled. Large stroke bounding boxes can still be expensive. Spatial layers use a conservative 128 MiB/eight-entry LRU, including retained sources/masks, but no per-stage cache. A prepared layer exceeding that budget is recomputed. Enabled style outputs are preflighted against a 512 MiB per-layer estimate; this is not a process memory cap. Gaussian scratch is tiled, while evaluated foreground/style rasters are retained full-size. Only parameter-preview processing supports in-flight cancellation; resize/preparation and main render work can delay cancellation. Rendering is CPU; wgpu presents the result. The measured region timings exclude input, texture conversion/upload and presentation; they do not establish smooth 4K/8K interaction.
- Recent files and recovery persist under the platform application-data directory. Recovery covers committed document edits, not in-flight text/construction drafts, undo history or viewports. A snapshot is approximately every 30 seconds when edits are stable; the last interval can be lost after a crash. No backup browser or snapshot retention policy yet. A damaged recovery sidecar reports an error; its valid .palette file can be opened manually. Old lease files are retained, while locked live instances are skipped. Profile conversion is not implemented: imports become RGBA8 with an sRGB working interpretation; supported ordinary decoders preserve original ICC/Exif bytes in the native project and apply Exif orientation. Flat exports omit metadata, and AVIF import metadata preservation is pending.
- GIF imports one frame and exports a still image with palette/transparency limitations. Animated WebP imports its first frame, APNG imports its PNG default image and TIFF imports its first page. Open and import-as-layer display explicit notices; animation/multipage editing and unusual metadata remain unsupported. JPEG export uses white for transparency. Ordinary codec tests use small fixtures; they are not a comprehensive conformance/fuzz suite.
- Native dialogs are synchronous modal dialogs; decoding/encoding/rendering run in background workers. Four concurrent file jobs are allowed; further requests report an error.
- Canvas crop/resize changes bounds while retaining hidden source pixels. Painting/movement expands the active source buffer as necessary; masks are reanchored with it. Selection move/resize/rotation now previews processed pixels on a background worker. Movement is integer-only. Resizing clamps crossing edges to one pixel rather than flipping; Shift retains aspect ratio within pixel rounding. Resizing is bilinear, with no interactive nearest-neighbor option yet.
- Flip/rotation commands act on active-layer selected source pixels when coverage is present; otherwise they transform the whole document. Selected pixels moved outside canvas bounds are clipped. Quarter-turn selections use a stable integer-grid center, so odd/even dimensions can align slightly differently from exact half-pixel centers. Custom angles resample with premultiplied bilinear arithmetic; repeated arbitrary rotations lose detail. Selected transforms retain local masks/filters/effects in place and do not bake their appearance. Whole-document rotations transform local coverage planes; locked layers participate in whole-document operations, while selected transforms respect the active lock. Source/output geometry and staging planes are preflighted against bounded allocations; this is not a cap on peak process memory.
- Completed shapes become raster selections on the current layer, not independently editable vector objects. Their selected bounding area can include existing source pixels enclosed by the shape; an existing selection still clips drawing and the resulting selection. Polygon and Curve are construction drafts until explicitly finished. Escape or changing tools/documents cancels an unfinished draft; drafts are not saved. Their width/colors/opacity are captured when construction starts. Complete the draft before changing those settings.
- Selection outlines now animate as marching ants, including holes and moving/creation previews. Boundary topology is cached at 50% coverage; edits and bounds retain nonzero coverage. Polygon selection and morphology remain pending. Brush/feather previews build contours on workers and scan nonzero bounds; other large coverage-mask construction/outline caching can still happen on the UI thread.
- Fill is contiguous and samples the active source layer in premultiplied RGBA with a per-channel tolerance. It is not a perceptual magic wand or all-visible-layers sampling tool. Live filters may change its displayed colors.
- Clipboard copy/cut samples the active layer's evaluated appearance, not the merged document. Paste creates a raster layer; it does not recover layers from flat clipboard data. Native image-paste events pass through egui's premultiplied ColorImage conversion, which may round low-alpha RGB. Host clipboard ownership/navigation was not destructively exercised during tests; synthetic native paste events and the core RGBA copy/cut/paste paths were tested. Linux/Wayland and macOS clipboard behavior remain untested locally.
- Selection-handle previews retain an immutable COW document snapshot and share the bounded full-composite worker. Intermediate previews can lag on large images; running jobs are not cancelled. Normal release commits only the exact final target. A tool/tab/save/close command finishes a still-pending target synchronously to preserve it, which can stall the interface on large selections. Canvas-resize handles are hidden in Select mode while a selection exists, avoiding conflicting controls at the same corner. No tiled/GPU transform preview or persistent untransformed floating content across completed gestures yet.
- Expensive fills/moves/transforms run one at a time on background snapshots. Results are discarded if their tab changes or closes; obsolete workers finish rather than being interrupted. Canvas painting is temporarily disabled while an edit job runs. Property sliders/text renaming still create commands for individual changes rather than coalescing a full gesture.
- New documents and the Image Properties Default action use 1280 x 720 at 100% zoom. The full canvas can extend beyond a narrow workspace; pan or Fit reveals its edges and resize handle. Whole-layer movement is integer translation; resizing/rotating an individual layer, unlinking masks and moving shape objects remain pending. Layer drag previews use progressive full CPU renders, not GPU transforms or tiled movement.
- Integer zoom uses nearest sampling. Fractional coordinates are correct, but smooth downsampling, comprehensive DPI and keyboard/screen-reader testing remain pending.
- Distribution installers, macOS app signing/notarization and Linux packages are not produced by this milestone.

- Still AVIF uses avif-decode 3/rav1d and ravif 0.13/rav1e. Windows tests cover 8-bit RGBA, opaque RGB, single-pixel and 10-bit input, quality changes, dimensions, alpha and malformed/truncated input. 12-bit conversion is implemented but not independently tested. Animation/non-still streams and HEIF irot/imir/clap properties are rejected explicitly; HDR/color-management, derived-image conformance and broad external fixture/fuzz coverage remain pending. Encoding uses 8-bit RGB with maximum alpha quality; it is not a lossless project format. Decoder scratch allocations and running jobs are not fully cancellable. Rust 1.98+ and NASM on x86/x64 are required; no system AVIF library is needed.
- Image-as-layer import uses the existing paste semantics: it preserves other layers, selects the new raster and expands canvas bounds for a larger image. If the target document changes during decode, the import is cancelled with a status message. Four file jobs and one recovery job can run; recents use last-writer-wins storage across simultaneous app instances.

- Phase 4 selection/mask slice: Wand uses Oklab distance with alpha as a separate dimension in assumed sRGB; it is not an ICC-managed comparison. Tolerance 100 explicitly selects every eligible canvas pixel. Antialiasing smooths the hard region by a one-pixel tent, so a boundary can include neighboring partial coverage. The contiguous frontier is capped at one million pending spans and the exact-color cache at 4096 entries. Existing 64-megapixel mask bounds apply; merged sampling also allocates a composite.
- Feathering uses pixel-integrated Gaussian weights below 5 px and a three-box Gaussian approximation at larger radii (radius is sigma, 0–128 pixels), with byte rounding between passes and clamped canvas edges. Small-radius processing has a bounded wider convolution cost; fractional changes still obey RGBA8 coverage precision. Selection feathering previews current coverage on a bounded background worker, retaining the original until toolbar release or dialog Apply. Intermediate slider requests are coalesced; obsolete running work finishes and is discarded, so very large masks can lag. Explicit tool/tab/save/undo actions finish a pending toolbar adjustment synchronously when its final worker result is not ready; this can stall that action. Layer-mask feathering still has no live preview. Toolbar settings also set the radius for each new rectangle, lasso or Wand region before combination, rather than repeatedly blurring the accumulated result. Creation previews show the raw contour, then the committed feathered/combined selection. Ordinary ants trace the retained original contour (or 50% coverage for selections without an original). Faint ants show the feather’s nonzero byte-coverage extent, which can extend farther than the nominal Gaussian sigma radius. Legacy feathered selections have no recoverable original contour until a new selection/feather operation establishes one.
- Layer masks have create/from-selection, thumbnail, enable, invert, feather and delete controls. Painting into masks, direct mask canvas view, unlinking from layer positions and permanent application remain pending. Ordinary brushes still edit source pixels. Locks block mask changes but do not block read-only Wand sampling. Obsolete workers are fenced on completion rather than interrupted.

- Selection feathering retains the original coverage, and subsequent dialog adjustments use that original rather than accumulating blur; zero restores it. Mixed combined selections do not retain a single live radius node. Layer-mask feathering still edits current mask coverage cumulatively. Disabled masks retain their stored coverage and disabled state during feathering. Unfeathered rectangle creation/combination still commits synchronously on release; large dense mask combinations can stall that frame. Feathered rectangles, lasso, Wand, mask-property operations and feathering use worker snapshots.

- Freeform selection is a closed freehand contour, with even/odd filling for self-crossings and four-sample antialiasing. Extremely long gestures are decimated at 4096 points, retaining endpoints; this can simplify details. Fewer than three retained points leave selection unchanged. Selection-tool settings belong to each open tab but are not serialized in native projects; committed coverage is preserved. Polygonal selection is pending.

- Selection brush uses an independently implemented connected color-range test inside the continuous swept footprint, sampled at stroke start. It does not perform Photoshop's proprietary full-object segmentation, AI selection or its combined brush/lasso gestures. Start another stroke to sample another color; turn color matching off to paint unrestricted coverage. Current-layer sampling evaluates filters/masks/opacity; all-visible sampling includes canvas backing. Pressure, oval tips, configurable spacing and automated edge enhancement remain future work. Settings are pinned during a stroke. Paths are bounded to 16384 input samples; reaching the limit cancels the draft with an error. Workers coalesce preview requests and discard stale results but do not interrupt running computation. Explicit tab/tool/save commands can synchronously finish the exact pending target. Large dense selections/overlays still use full byte planes and can lag; the benchmark excludes texture conversion, GPU upload and presentation. The original and feather contours remain visible with an optional cyan coverage overlay.

At a one-pixel selection-brush diameter, the tip snaps to pixel centers and uses a hard antialiased footprint; this prevents empty soft dabs and disconnected diagonal strokes at that scale.

Phase 5 measured scope: 1280 x 720 blur+shadow+glow was ~0.37 s cold / 0.071 s cached; 3840 x 2160 was ~3.0 s cold / 3.1 s repeat because the prepared stack exceeded the cache budget. These optimized-development CPU timings exclude UI/texture upload and are not 4K responsiveness claims. See [Phase 5 validation](docs/PHASE5_VALIDATION.md).

Layer processing controls: numeric/color parameters are selected one at a time to preserve the compact Text/Selection toolbar height. Drafts temporarily block painting and editing shortcuts; pan/zoom and Apply/Cancel remain available. Tool/tab/layer changes cancel unapplied drafts. Full-resolution canvas results replace applied previews in the background. The preview above 2048 px is reduced and may differ from final output. See [layer control validation](docs/LAYER_PROCESSING_UI_VALIDATION.md).

Expanded catalog limits: Median uses a bounded 0–5 px component-wise premultiplied RGBA rank filter; dense/noisy images and larger radii can be expensive. Box Blur is limited to 0–32 integer pixels. Stroke supports fractional square morphology and coverage-weighted Euclidean round contours; rounded growth uses an additional full f32 distance plane plus byte coverage scratch. HSL Vibrance has no skin-tone protection; Black & White is a weighted encoded-RGB adjustment. Inner styles recolor existing masked coverage without increasing its alpha. Curves currently provides five fixed input knots and shared RGB output values, without a graph, arbitrary control points or per-channel curves. Motion Blur uses bounded straight-line sampling (0–64 px); Mosaic is layer-local (1–128 px); reduced previews may shift noise samples or block boundaries. Seeded Gaussian noise is repeatable on the tested platform; cross-platform transcendental last-bit identity is not asserted. Filter Gallery, remaining styles and broad color-management work remain pending. Native v5 retains the binary asset layout while version dispatch protects the new Stroke boolean. See [current controls, filters and measurements](docs/STYLE_FILTER_CONTROLS_VALIDATION.md).

Current conventional menu: unfinished filters appear disabled within their researched branches; Filter Gallery is explicitly disabled. No Gallery sample assets/window are built yet. Average computes full layer-local premultiplied RGBA mean (including transparency); filter masks blend afterward. Find Edges uses per-channel Sobel; Emboss uses a directional grayscale difference. Neither grows alpha or outlines a silhouette using invisible RGB. Minimum/Maximum use square visible-RGB extrema, preserve center alpha and ignore fully transparent neighbors; radius is 0–16 integer px and the separable intermediate costs six bytes/pixel. Unsharp Mask has per-channel thresholding; Twirl is centered on the source bounds; Wave is one sinusoidal axis with amplitude/wavelength/direction and boundary choices. No proprietary parity, arbitrary distortion control points, custom kernels or full Gallery implementation is claimed. See [current evidence](docs/FILTER_MENU_VALIDATION.md).

Creative filter limits: Surface Blur uses a full 2D Gaussian spatial/linear color-range kernel, radius 0–8 integer px, and preserves source alpha; larger radii/dense images are more expensive. Radial Blur uses a source-centered uniform Spin/Zoom sampler (2–64 samples); no movable center or proprietary quality modes. Clouds/Difference Clouds are five-octave seeded value-noise fields and introduce opaque coverage across source bounds, blended through existing filter/layer masks; colors and scale are stored parameters. Poster Edges combines quantization, Sobel edges and square thickness growth. Grain supports Regular, Soft, Speckle, Horizontal and Vertical patterns, rather than every Photoshop grain variant. Fragment is a premultiplied four-copy cross average with editable 0–32 px offsets (default 2), scaled for previews. These are independent equivalents, not Photoshop-identical rendering. Reduced previews approximate spatial/noise scale. See [current domains, evidence and timings](docs/CREATIVE_FILTERS_VALIDATION.md).

Noise/distortion batch: Despeckle uses a fixed sigma-0.8 Gaussian with a 3×3 Sobel guard (64 encoded levels), rather than segmentation; adjacent flat-region Gaussian footprints may soften the edge fringe. Dust & Scratches uses bounded premultiplied component medians (0–5 px) and a replacement threshold, retaining center alpha. Reduce Noise uses a bounded 0–4 px Gaussian/range neighborhood with independent luminance/chroma mixing and optional detail boost; it does not implement a JPEG-artifact mode or per-channel advanced editor. Pinch/Spherize are source-centered circular inverse mappings, radius 0–4096 px; Ripple is a concentric sinusoidal inverse displacement with clamped edges. Sharpen/More are fixed four-neighbor high-boost kernels. These definitions are independently implemented conventional equivalents, not Photoshop-identical results. Exact parameters, partial-alpha policy and CPU timings: [current validation](docs/ORIGIN_FILTERS_VALIDATION.md).

Movable-origin/filter batch: origins are normalized to source pixel centers and clamped inside the active layer. Wave uses the origin for phase (top-left default preserves old projects); circular filters default to the middle. Polar conversion has a fixed half-short-axis radius, horizontal angular wrap and repeated radial edges, without a separate radius control. ZigZag is an independent envelope/sinusoid equivalent, not Adobe pixel parity. Fibers generates opaque source-sized color, with density/length relative to layer dimensions; Glowing Edges preserves original alpha and detects RGB transitions, so an isolated flat-color silhouette is not outlined against transparency. Origin markers require Preview and placement mode. Destructive source transforms do not currently rotate/flip the stored filter parameters. See [scope and measurements](docs/ORIGIN_FILTERS_VALIDATION.md).

Artistic/print/texture batch: Cutout uses a maximum eight-color encoded-RGB palette trained on a bounded 5-bit histogram, with six deterministic clustering passes and a Gaussian/source fidelity blend; it does not build editable vector or connected cut-paper regions. Film Grain is seeded monochrome noise with highlight protection, without film-stock simulation. Accented Edges/Ink Outlines use independent derivatives and retain source alpha, so they do not trace flat silhouettes against transparency. Photocopy is a tonal/edge stencil, not a physical copier model. Halftone Pattern has Dot/Line/Circle screens and source-local alignment; it is distinct from the still-disabled CMYK Color Halftone filter. Patchwork uses coverage-weighted cell means, not a histogram mode; relief is a one-pixel cell bevel. Craquelure uses jittered local nearest-site gaps, without a physical fracture simulation. Preview resampling can change palettes/noise/grid phase; small implicit guide/bevel/crack widths remain in preview pixels. Exact scope is in [artistic filter validation](docs/ARTISTIC_FILTERS_VALIDATION.md).

Pixelate/cell batch: Color Halftone uses four mathematical subtractive screens in encoded RGB, without ICC press separation or Photoshop-identical dots. Crystallize/Pointillize/Stained Glass use seeded jittered lattice sites, local polygon boundaries and alpha-weighted mean cell colors; they do not use arbitrary imported tessellations. Cell work uses a bounded two-cell halo and recomputes labels rather than retaining a full-image label map. Stained Glass has cell lighting and borders, not a refraction/material simulation. Mosaic Tiles has square cell means and light/dark grout. Facet is an independent minimum-variance quadrant equivalent. Mezzotint provides ten repeatable mark types, with monochrome or saturated-channel color. Diffuse retains original alpha; its anisotropic mode is one edge-preserving step, and the seed is disabled in that mode. Preview resampling may shift grids, dots and noise. The current menu has no unimplemented enabled entries (137 catalog filters), excluding Gallery and layer effects; [inventory](docs/FILTER_INVENTORY.md) and [scope](docs/PIXELATE_FILTERS_VALIDATION.md).

Adjustment batch: Color Balance uses encoded-RGB smooth tonal windows and optional Rec.709 luma protection. Photo Filter models a linear-light absorbing color; luma protection is in encoded RGB. Channel Mixer supports a 3×4 RGB matrix; monochrome uses the first row and temporarily disables other rows' controls without discarding them. Gradient Map is a two-stop encoded-RGB gradient with midpoint/reversal; arbitrary stops, imported gradients and dithering remain pending. Selective Color uses independent soft RGB/CMY and achromatic memberships with nine stored CMYK ranges; it is an RGB equivalent, not ICC-managed CMYK or Photoshop-identical separation. Shadows/Highlights offers separate amounts, tone widths and radii using alpha-weighted Gaussian color guides; advanced color/contrast/clip controls remain pending. Blur/Blur More use fixed 3×3/5×5 premultiplied box kernels. Reduced previews approximate local guides and fixed tiny kernels. Color Lookup stays disabled until a real LUT workflow is implemented. [Scope and evidence](docs/ADJUSTMENT_FILTERS_VALIDATION.md).

Painting batch: all eight traditional-media equivalents keep destination alpha, including Spatter, so they recolor/smear existing coverage rather than scatter or create transparency. Colored Pencil uses finite crossed segments over a captured paper RGB color; it is not a physical pencil simulation. Dry Brush uses sampled low-variance sectors, color quantization and seeded dry texture. Paint Daubs supplies three independent Round/Square/Diagonal geometries, without claiming Photoshop's proprietary brush types. Nine-tap diagonal strokes approximate long smears; fixed short/long Dark Strokes and finite Crosshatch patterns are source-coordinate anchored. Spatter uses seeded disk displacement followed by optional alpha-weighted smoothing. Reduced previews can shift texture phase and small kernel coverage. Dense photos and large radii remain CPU workloads; background preview cancellation does not establish GPU or per-stage caching. [Exact controls and evidence](docs/PAINTING_FILTERS_VALIDATION.md).

Drawing batch: Sprayed Strokes uses nine range-weighted color samples along a selected axis with seeded perpendicular spray; it does not scatter alpha or perform global dominant-color segmentation. Sumi-e uses a Gaussian wet-color guide plus tonal/edge ink darkening, rather than physical ink transport. Sketch equivalents retain alpha and saved ink/paper colors. Graphic Pen uses finite supersampled lines; Charcoal uses smudged tonal coverage, bold edges and quarter-step ink; Chalk & Charcoal uses a midtone base plus independent textured dark/light regions. Bas Relief derives normals from blurred luminance with fixed light elevation and editable azimuth; Note Paper combines soft cutouts, fixed-direction relief and seeded grain. Stamp is smoothed, antialiased two-color thresholding. These are independently implemented RGB equivalents, with no Photoshop-identical output claims. Preview resampling can change small marks and textures. [Controls and evidence](docs/DRAWING_FILTERS_VALIDATION.md).

Sketch completion: Chrome uses a grayscale folded height/slope reflection ramp, without environment maps or physical metal reflection. Conté Crayon uses four generated material heights and saved ink/paper emphasis, with texture size, relief, light angle, inversion and seed; imported texture files remain unsupported. Plaster shades a smooth inverted-luminance height field at fixed light elevation, with editable azimuth. Reticulation is seeded coherent clump/fine-grain modulation, not physical film chemistry. Torn Edges perturbs a soft tonal cut with stored-seed noise; original alpha is retained. Water Paper pools source colors through a bounded nine-tap wet-fiber guide plus generated fibers; it does not simulate fluid transport or create new coverage. Reduced previews can shift grain, reflection bands and texture phase; large full-resolution CPU renders can still lag. [Exact controls and evidence](docs/EDITABLE_FILTERS_VALIDATION.md).

Artistic completion: independent bounded paint/tonal/surface equivalents, not proprietary renderer parity. Fresco/Palette Knife/Underpainting/Watercolor use stratified least-variance neighborhoods; fine structures and long strokes are approximated. Neon Glow is a softened two-color tonal mapping with a movable glow band, not optical bloom; glow size is dimensionless. Plastic Wrap uses a luminance height field with fixed illumination/view and a flat-field highlight baseline, not physical film/refraction. Sponge has seeded pores, not a physical sponge simulation. Pastel/underpainting materials are generated Canvas/Brick/Burlap/Sandstone, with no imported textures. Color is processed in encoded sRGB; alpha stays at original coverage. Reduced previews can shift textures/edges; fixed internal paint/Neon neighborhoods are not exact full-resolution previews. CPU-only full-layer evaluation and memory/cache limits remain; main render targets now cancel obsolete jobs. [Validation](docs/EDITABLE_FILTERS_VALIDATION.md).

Optical/texture batch: generated glass surfaces only (Frosted, Tiny lens, Blocks, Canvas), without imported maps/refraction physics. Ocean Ripple uses coherent random phases and two intersecting waves. Both inverse-map within original bounds and expose Wrap/Repeat/Transparent edges. Diffuse Glow screens a colored, seeded highlight veil with a source-centered fade; color captures the background only when added. Texturizer shades generated surfaces with a fixed light elevation. Shape Blur has five generated apertures, four coverage samples per kernel cell and radius 0–16 px; small radii quantize and dense large-radius convolution can be expensive. Smart Blur radius is limited to 0–8 integer px, with a compact range kernel and three modes; no quality option. Smart Sharpen is 1–6 damped Gaussian-PSF back-projection iterations with a residual noise threshold; no blind/lens/motion deconvolution or Photoshop advanced shadow/highlight controls. Iterations use RGBA8 intermediates and can clip or amplify ringing. Other CPU/cache/cancellation, color-management and reduced-preview limits still apply. [Exact scope](docs/EDITABLE_FILTERS_VALIDATION.md).

Stylize/render batch: independent equivalents, not Photoshop-identical algorithms. Extrude projects average-color blocks/pyramids over the original backing; four coverage samples and far-to-near ring ordering approximate faces, without a depth buffer, original-textured fronts or mesh export. Overlapping translucent faces can accumulate alpha. Oil Paint uses bounded edge-tangent sampling and generated bristles, not fluid/impasto simulation. Tiles uses integer seeded offsets up to half a tile and explicit gap fills; overlap order is row-major and output clips to the source bounds. Trace Contour is a one-pixel per-channel level crossing. Wind uses bounded row sampling, so long trails are approximate. Lens Blur supports Uniform/Alpha/Luminance depth from the current raster, not imported depth maps; its at-most-121-tap aperture/depth rejection approximates bokeh/occlusion and can alter transition coverage. No focus eyedropper or ray tracing. Lens Flare uses generated optical components rather than branded physical lenses. Lighting Effects has one light and an optional luminance height field; no multi-light presets, imported bump maps or cast shadows. CPU processing, preview resampling and memory/cache limits remain. Default Lens Blur measured 6.63 s cold at 4K on a quarter-coverage workload; dense images and end-to-end interaction may cost more. [Exact scope](docs/EDITABLE_FILTERS_VALIDATION.md).

Editable catalog completion: independent implementations, not Photoshop-identical control/output parity. Color Lookup imports only UTF-8 3D `.cube` tables (size 2–33, 4 MiB text limit); no 1D/shaper LUTs, 3DL/CSP/device-link formats, tetrahedral interpolation or profile conversion. Output is trilinear encoded RGB, with byte rounding; domains and finite table values are bounded. Displacement maps are limited to 1024×1024 PNG/JPEG/BMP/GIF/TIFF/WebP, use red/green with 128 neutral and ignore blue; transparent coverage reduces displacement. Channels are taken from oriented decoded pixels, without profile transforms. Animation/page notices use the existing first-frame/page policy. No PSD map importer. Shear has five fixed-height horizontal knots with linear/bounded Catmull–Rom interpolation, not arbitrary point counts. Custom uses a fixed 5×5 signed kernel, nonzero scale, offset and optional alpha filtering; no arbitrary kernel sizes or kernel-file import/export. Preserve-alpha mode fills missing/less-covered neighbor color from the center to prevent fringes; alpha mode convolves premultiplied RGBA and can clip signed results. Asset decode/parse is background work tied to a draft; abandoning a job drops its result, without interrupting a running codec. Native file chooser interaction itself is not automated. Existing full-render/cache/color-management and cross-platform gates remain. [Validation](docs/EDITABLE_FILTERS_VALIDATION.md).

Expanded catalog: 132 conventional filters does not mean every Photoshop capability. Seven wholly missing audited Neural Filters plus partial neural/conventional coverage, raw development and previously excluded tools remain unavailable; [audit](docs/PHOTOSHOP_FILTER_AUDIT.md). Field Blur supports eight bounded pins; Iris/Tilt-Shift/Spin use one region per instance, Path uses one quadratic curve. Variable-focus defocus interpolates six Gaussian scales; Path/Spin have bounded 25/33-tap shutter sampling. Procedural frames/fire/trees are original, with four frame styles and three tree forms rather than Adobe preset/species assets. NTSC is a conservative legacy gamut approximation, not color-managed broadcast certification. [Exact scope and evidence](docs/GALLERY_VIDEO_RENDER_VALIDATION.md).

Expanded photographic defaults measured about 4.05–4.44 s for cold 4K variable-focus blur and 5.24 s for Path Blur on the documented quarter-coverage workload. Spin and other new operations measured roughly 0.22–0.36 s. Dense input/end-to-end interaction can cost more; the current CPU path is not a frame-rate guarantee.

The external audit also records the unimplemented Substance-based Parametric Filters family separately from Neural/AI and the 132 conventional entries; see [coverage audit](docs/PHOTOSHOP_FILTER_AUDIT.md).

Neural follow-up: one bundled Mosaic Style Transfer profile is implemented locally. It uses a 224 × 224 working image fitted without aspect distortion; small details are limited, arbitrary reference styles and high-resolution inference are not supported. Alpha is preserved, with a gray inference matte for transparency. JPEG Artifacts Removal is also implemented with the bundled DnCNN-3 luminance network. It preserves source alpha/chroma but cannot reconstruct chroma compression damage; dense large images remain expensive CPU workloads and large previews are reduced. A 128 MiB bounded source/restoration cache accelerates strength changes. Colorize also runs locally with 256² semantic inference and a 64² chroma field. It reuses original Lab luminance/alpha but gamut clipping can shift displayed luminance; predicted colors are not guaranteed historical colors. Face-guided Skin Smoothing now uses learned geometry with conventional smoothing. Smart Portrait remains unimplemented; Super Zoom now supports learned cropped magnification, with genuine output-size changes still missing. Model planning and each individual operator finish before cancellation is observed. No cloud or external runtime is used; macOS/Linux inference and broad photographic quality have not been validated. [Exact status](docs/NEURAL_FILTERS_FIRST_SIX.md).

JPEG restoration has a substantial initial CPU cost: the dev-build opaque 1280 × 720 benchmark measured 65.22 seconds on this machine, while a cached strength change took 44.65 ms. UI and cancellation remain responsive; this is not instantaneous high-resolution cleanup. [Measured scope](docs/JPEG_RESTORATION_VALIDATION.md).

Colorize adds about 64.5 MB of bundled weights. Inference is float32 with compact fp16 convolution-kernel storage; the profile identity pins these quantized weights and the pixel contract. The low-resolution color field can bleed across edges and infer incorrect colors. No user hints, arbitrary colorization models, ICC/HDR adapter or cross-platform runtime acceptance is supplied. [Exact scope](docs/COLORIZE_VALIDATION.md).

Face-guided Skin Smoothing uses learned facial geometry with explicitly
conventional smoothing, not a learned skin-restoration network. The short-range
128² detector may miss small, occluded, profile or inverted faces; no detection
leaves the source unchanged. It treats at most eight faces and has 384² working
patches. Geometry coverage protects eyes/lips/brows but does not semantically
segment beards, glasses, makeup or hair inside the face; use filter masks for
those cases. Neck/hands/body skin and manual targeting of missed faces are not
supported. Two NASA portraits plus roll/multiple-face regression checks do not
establish broad photo-quality/fairness acceptance. [Exact scope](docs/SKIN_SMOOTHING_VALIDATION.md).

Super Zoom currently produces a same-canvas crop with a fixed 3× luminance
network, editable magnification up to 3×, Enhancement and a source center.
Canvas/file dimensions do not increase. Larger-document output, arbitrary
scale factors, face-specific restoration and denoising controls remain missing.
Color is bilinear, alpha geometric; the model may ring, soften or invent detail.
This is partial coverage, not Photoshop parity. [Exact scope and evidence](docs/SUPER_ZOOM_VALIDATION.md).
